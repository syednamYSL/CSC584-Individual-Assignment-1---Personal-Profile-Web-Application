# CSC584 Individual Assignment 1 - Personal Profile Web Application

A simple web application that collects personal profile information in an HTML form, sends it to a Java Servlet using HTTP POST, and displays it on a JSP page.

## How to Run

1. Install JDK 8 and NetBeans 8.2 (Java EE bundle, which includes GlassFish 4.1.1).
2. Clone or download this repository.
3. In NetBeans: Go to **File** → **Open Project** and select the project folder.
4. Right-click the project and select **Clean and Build**.
5. Right-click the project and select **Run** (or press `F6`).
6. Open [http://localhost:8080/PersonalProfileApp/](http://localhost:8080/PersonalProfileApp/) in your browser.
7. Fill in the form and click **Generate Profile**.

## Data Flow

HTML Form (POST) → ProfileServlet → profile.jsp
